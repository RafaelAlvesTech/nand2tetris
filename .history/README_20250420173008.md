# Projeto 01 - Nand2Tetris no VSCode

## Pré-requisitos
- Visual Studio Code instalado
- Extensão Nand2Tetris IDE instalada

## Como usar

1. Abra a pasta do projeto no VSCode.
2. Implemente cada chip (`Not.hdl`, `And.hdl`, etc.) conforme o especificado.
3. Para testar, clique com o botão direito no arquivo `.tst` e execute o teste.
4. Verifique se todos os testes passaram.

## Dicas
- Use os snippets da extensão para agilizar.
- Consulte os arquivos `.cmp` para entender os resultados esperados.
